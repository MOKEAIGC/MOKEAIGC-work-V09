MOKEAIGC V9 是一套面向 AI 图像生成的电影提示词导演 Skill。
它可以接收一句灵感、一种氛围、一个地点、一段场景描述或一张参考图，并将其扩展为 9 组视觉统一、具有真实生活痕迹和电影叙事感的静帧提示词。
它强调“被镜头发现的瞬间”，而非摆拍、海报、角色陈列或概念设计图。每条提示词都会明确主体行为、空间层次、镜头角度、具体焦距、光线、材质与环境痕迹，使所有画面看起来属于同一个可信世界或同一部电影。
两种创作模式
世界观模式：从居民、动物、建筑、地景、日常、迁徙、文化、权力和肖像九个切面，逐步揭示一个完整世界。
视觉构图模式：保持同一个核心场景不变，使用九种不同的角度、景别、焦段、调度和构图方式探索它的多种拍法。
核心功能
一次生成恰好 9 组电影静帧提示词
支持文字灵感、场景描述与参考图输入
中英文提示词一一对应
每个镜头标注具体焦距
提供独立的摄影与灯光字段
维持人物、建筑、材料、气候和色彩连续性
自动加入胶片颗粒、光学质感和环境磨损
支持 21:9、16:9 与 9:16 画幅
适配 Midjourney、Nano Banana Pro、GPT Image 2
支持 Midjourney --sref、--profile 与多档 --stylize
可叠加“科幻浪漫极简”等统一视觉基调
适合用于
虚构世界与视觉文化开发
电影、短片和游戏项目前期探索
提案视觉与情绪板制作
从参考图反向扩展世界观
同一场景的镜头与构图测试
批量生成风格连贯的 AI 电影剧照
不适合用于
单张一次性图片提示词
角色设定表或标准立绘
视频运镜与连续动作提示词
已锁定剧情的视频分镜生成
